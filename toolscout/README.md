# ToolScout

Bilingual (English/Hebrew) static website with four browser-side calculators and an editorial/monetization plan.

## Live site
After GitHub Pages deployment completes: https://meirvbb-png.github.io/cryptppilot-ai/

## Deployment
The `.github/workflows/pages.yml` workflow deploys the `toolscout/` folder to GitHub Pages on every push to `main`. In repository Settings → Pages, set Build and deployment source to **GitHub Actions** if it is not already selected.

## Included
- English home page and Hebrew RTL home page
- Hourly-rate, subscription-cost, percentage-change and VAT/tax calculators
- Privacy and contact pages
- Sitemap and robots.txt
- Automated quality checks and GitHub Pages deployment

## Monetization status
No affiliate links or revenue mechanisms are active yet. Apply to affiliate programs only after the site has useful original content and add disclosed, verified links after approval. Traffic, approval and income are not guaranteed.

## Local preview
Run `python -m http.server 8000` from this folder and open `http://localhost:8000`.

This is an initial website, not a guaranteed income source.
