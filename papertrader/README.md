# Paper Trader – מסחר דמו בלבד ($450)

אפליקציית ווב מובייל-פירסט. **אין חיבור לחשבון אמיתי ואין מפתחות API** – רק נתוני שוק ציבוריים (ccxt: Bybit + MEXC) וסימולציה מקומית (SQLite).

- `agents.py` – 3 סוכנים בצינור (אנליסט טכני ← אסטרטג ← מנהל סיכונים), אינדיקטורים ב-`pandas-ta` (EMA/RSI/ATR/MACD/נפח). סיכון 1.5%–2% מהתיק, כולל עמלות, מינוף מחושב כך שה-SL רחוק מהליקווידציה. הסוכנים מבוססי חוקים (ללא LLM/מפתח).
- `engine.py` – מנוע דמו: Market/Limit, עמלת Taker 0.055%, בדיקת SL/TP1/TP2/ליקווידציה מול נרות 1m אמיתיים + מחיר חי כל 3 שניות (אם SL ו-TP באותו נר – SL קודם, שמרני). ב-TP1 נסגר 50% וה-SL עובר לכניסה.
- `app.py` + `static/index.html` – FastAPI + ממשק טלפון (גרף נרות עם קווי Entry/SL/TP).

## הרצה
```
pip install -r requirements.txt
uvicorn app:app --host 0.0.0.0 --port 8000
```
או Docker (`docker build -t pt . && docker run -p 8000:8000 -v pt:/data pt`). לגישה מהטלפון יש לארח בשרת **באזור שאינו חסום ע"י Bybit** (Bybit חוסם ארה"ב ועוד).

`PT_MOCK=1` – סימולטור אופליין לבדיקות בלבד (מסומן באדום בממשק). `pytest tests` להרצת הבדיקות.
